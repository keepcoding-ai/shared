# eitri-desktop

App de computador da Eitri — a mesma casa de `https://eitri.keepcoding.app/so/`, numa janela própria.

## Baixar (Mac, Apple Silicon)

[Eitri_0.1.2_aarch64.dmg](https://github.com/keepcoding-ai/shared/releases/download/eitri-desktop-v0.1.2/Eitri_0.1.2_aarch64.dmg)

## Instalar

1. Abra o `.dmg` e arraste **Eitri** para **Aplicativos**.
2. O app ainda **não é assinado pela Apple**. Na primeira vez, o Mac bloqueia:
   clique com o botão direito em **Eitri** → **Abrir** → **Abrir**.
   Se aparecer "está danificado", rode no Terminal:
   ```
   xattr -dr com.apple.quarantine /Applications/Eitri.app
   ```
3. Entre com a sua conta da Eitri.
