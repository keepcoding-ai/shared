# processa-desktop

App de computador da **Processa OS**: uma janela própria que abre o Processa OS (https://processa.keepcoding.app/so/) com a marca da Processa, sem precisar do navegador.

## Baixar (Windows 64 bits)

[processa-os-1.0.0-win-x64-setup.exe](https://github.com/keepcoding-ai/shared/releases/download/processa-desktop-v1.0.0/processa-os-1.0.0-win-x64-setup.exe) — instalador (recomendado)

Também há o [.msi](https://github.com/keepcoding-ai/shared/releases/download/processa-desktop-v1.0.0/processa-os-1.0.0-win-x64.msi), para instalação gerenciada, e uma versão [portátil](https://github.com/keepcoding-ai/shared/releases/download/processa-desktop-v1.0.0/processa-os-1.0.0-win-x64-portable.exe), que abre sem instalar.

## Instalar

1. Abra o instalador e siga os passos.
2. O app é assinado pela KeepCoding com certificado próprio, que o Windows ainda não reconhece. Se aparecer "O Windows protegeu seu computador", clique em **Mais informações** e depois em **Executar assim mesmo**. Isso só é preciso uma vez.
3. Abra o **Processa OS** pelo Menu Iniciar. O login abre no navegador do sistema.

Não há atualização automática: versão nova é instalar de novo por cima.
